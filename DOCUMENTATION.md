## 🛠️ Referência Rápida

### Comandos Principais

#### API
```bash
cd api
npm install          # Instalar dependências
npm run dev         # Rodar em desenvolvimento
npm start           # Rodar em produção
npm run migrate     # Rodar migrations
npm run lint        # Verificar código
```

#### Web
```bash
cd web
npm install         # Instalar dependências
npm run dev        # Rodar em desenvolvimento
npm run build      # Build para produção
npm run lint       # Verificar código
```

### Endpoints Principais

```http
POST   /sessions                 # Login
POST   /users                    # Registrar usuário
GET    /users/validated          # Listar usuários (protegido)
GET    /products                 # Listar produtos (protegido)
POST   /products                 # Criar produto (admin)
GET    /sales                    # Listar vendas (admin/sale)
```

### Rotas Frontend

```
/signin              # Login
/signup              # Registrar
/                    # Home
/product             # Produtos
/sales-report        # Relatório de vendas
/suppliers           # Fornecedores
```

## 📊 Fluxos Principais

### Fluxo de Autenticação

```
Usuário → Signup → Criar conta na API → Login
       ↓
       Credenciais → API autentica → JWT token retornado
       ↓
       Token armazenado (localStorage)
       ↓
       Requisições protegidas incluem token
```

Ver: [README.md - Fluxo de Autenticação](README.md#fluxo-de-autenticação)

### Fluxo de Autorização

```
Usuário autenticado
       ↓
       Acessa rota → Middleware verifica token
       ↓
       Middleware verifica role
       ↓
       Role matches → Acesso concedido
       ❌ Role não matches → Erro 403 (Forbidden)
```

Ver: [api/README_API.md - Middlewares](api/README_API.md#-middlewares)

### Fluxo de Desenvolvimento

```
git clone → npm install → npm run dev
       ↓
       Fazer alterações
       ↓
       Testar localmente
       ↓
       git commit → git push
       ↓
       PR review → Merge → Deploy automático
```

Ver: [CONTRIBUTING.md - Como Contribuir](CONTRIBUTING.md#-como-contribuir)
